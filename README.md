# 🏥 Healthcare Data Analysis – SQL & Power BI

An end-to-end **Healthcare Data Analysis project** using **MySQL** for data analysis and **Power BI** for interactive data visualization.

## 📌 Project Overview

This project analyses healthcare records to understand patient demographics, medical conditions, hospital information, admission types, insurance providers, and billing patterns.

The project covers the complete workflow:

**Raw Data → Data Cleaning → SQL Analysis → Power BI Dashboard**

## 🛠️ Tools & Technologies

* **Excel / CSV** – Dataset
* **Power Query** – Data Cleaning
* **MySQL** – Data Analysis & SQL Queries
* **Power BI** – Data Visualization & Dashboard

## 🧹 Data Cleaning

The healthcare dataset was cleaned and prepared before analysis.

The cleaned dataset was then used for SQL analysis and Power BI dashboard development.

## 🗄️ SQL Analysis

MySQL was used to analyse the healthcare dataset.

Key analysis includes:

* Total number of patients
* Patients by gender
* Maximum, minimum and average age
* Patients by medical condition
* Patients by admission type
* Top 10 hospitals by patient count
* Patients by insurance provider
* Highest, lowest and average billing amount
* Average billing by medical condition
* Total number of unique hospitals

The SQL queries use aggregation functions such as `COUNT()`, `MAX()`, `MIN()`, and `AVG()`, along with `GROUP BY`, `ORDER BY`, and `LIMIT`.

## 📊 Power BI Dashboard

Power BI was used to transform the analysed healthcare data into an interactive dashboard.

The dashboard provides insights into:

* 👥 Patient demographics
* 🏥 Hospital analysis
* 🩺 Medical conditions
* 🚑 Admission types
* 💳 Insurance providers
* 💰 Billing analysis
